# Game audio

The short effects in `kenney/` come from Kenney's CC0 packs:

- [Interface Sounds](https://kenney.nl/assets/interface-sounds)
- [Impact Sounds](https://kenney.nl/assets/impact-sounds)
- [RPG Audio](https://kenney.nl/assets/rpg-audio)

The original pack license texts are kept next to the files as
`LICENSE_INTERFACE.txt`, `LICENSE_IMPACT.txt`, and `LICENSE_RPG.txt`.

| Game event | Local file | Source pack |
| --- | --- | --- |
| Dialog typing | `dialogue_key.ogg` | Interface Sounds |
| UI click | `ui_click.ogg` | Interface Sounds |
| Battle start | `draw_knife.ogg` | RPG Audio |
| Die place / reroll | `drop.ogg` / `select.ogg` | Interface Sounds |
| Hit / hurt | `hit.ogg` / `heavy_hit.ogg` | Impact Sounds |
| Victory / defeat | `confirmation.ogg` / `error.ogg` | Interface Sounds |
| Location transition | `open.ogg` | Interface Sounds |
| Search / coins | `search.ogg` / `coins.ogg` | Impact Sounds / RPG Audio |
