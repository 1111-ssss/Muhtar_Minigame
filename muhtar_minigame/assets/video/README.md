# Ролики раздевалки

Положите в этот каталог ровно три локальных MP4-файла с этими именами:

- `buber_kartofla_1.mp4`
- `buber_kartofla_2.mp4`
- `buber_kartofla_3.mp4`

Игра использует ключи Flutter assets и передаёт их в `media_kit` как URI
`asset:///assets/video/<имя-файла>`, а не как абсолютные пути конкретного
компьютера. После добавления файлов запустите `make test` или `make build`,
чтобы Flutter включил их в bundle.

Сейчас в каталоге находятся только этот README, поэтому запуск сцены без MP4
преднамеренно заканчивается graceful error-панелью с точным списком ожидаемых
файлов. MP4-заглушки не добавляются.

Воспроизведение выполняется через `media_kit`, `media_kit_video` и
`media_kit_libs_video`, включая основную Linux desktop сборку. Ошибка открытия
ролика не должна закрывать игру: окно можно закрыть, а остальные локации
останутся доступными.
