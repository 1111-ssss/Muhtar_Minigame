# Ролики раздевалки Озона

Положите в этот каталог три локальных файла:

- `buber_kartofla_1.mp4`
- `buber_kartofla_2.mp4`
- `buber_kartofla_3.mp4`

Игра использует их как Flutter assets, а не как абсолютные пути с конкретного
компьютера. После добавления файлов запустите `make test` или `make build`,
чтобы Flutter включил их в bundle.

На Android, iOS и macOS проигрывание выполняется через `video_player`. На
Linux/Windows upstream-плагин может не иметь video backend; в таком случае
игра покажет понятное сообщение вместо падения, а остальные локации останутся
доступными.
