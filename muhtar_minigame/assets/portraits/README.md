# Портреты боя

Кидайте иконки/портреты персонажей прямо в эту папку:
`muhtar_minigame/assets/portraits/`.

Имена файлов должны совпадать с id бойца:

- `player.png` — игрок;
- `slime.png`, `goblin.png`, `gopnik.png`, `shaurmek.png`,
  `viktor_korneplod.png` — враги.

Рекомендуемый размер: 512×576, PNG, вертикальный портрет. Изображения
заполняют рамку через `BoxFit.cover`. Пока файла нет, отображается нейтральная
заглушка с именем, без программного рисунка персонажа.
