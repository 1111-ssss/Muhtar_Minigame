# Внешние референсы спрайтов

В проект добавлены локальные SVG-референсы для дерева и каменистого рельефа из
[Material Design Icons](https://github.com/Templarian/MaterialDesign).
Репозиторий распространяется по лицензии Apache-2.0.

В изометрическом Flame-слое используются пиксельные процедурные тайлы, поэтому
они сохраняют масштаб и не расплываются при повороте камеры. Рельсы — это
только тайлы карты (`8`), отдельного объекта состава или декоративной ленты
рельс больше нет.

План перехода на полноценные персонажные спрайты, тайлы, окружение, предметы,
UI и эффекты с подробными промптами находится в
[`docs/asset-generation-prompts.md`](../../../docs/asset-generation-prompts.md).
