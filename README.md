# Muhtar Minigame

- Игра на Flutter + Flame: [`muhtar_minigame/`](muhtar_minigame/README.md).
- **MuhtarBuild — редактор карт и PNG-портретов персонажей:**
  [`MUHTARBUILD.md`](MUHTARBUILD.md).

Запуск редактора из этой папки:

```bash
./MuhtarBuild
```

Нужен Flutter SDK с поддержкой Linux desktop. Без скрипта:
из `muhtar_minigame/` выполните `flutter run -d linux -t lib/muhtar_build.dart`.
